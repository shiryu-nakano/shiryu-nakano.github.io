### 📋 サーバーのスペック診断書

|**項目**|**ステータス**|**解説**|
|---|---|---|
|**OS**|**Ubuntu 20.04.6 LTS**|安定性の高いLinux。情報や対策がネットに一番多いOSです。|
|**アーキテクチャ**|**`x86_64`**|一般的なIntel/AMD系の64bit。ほぼ全てのツールがそのまま動きます。|
|**CPU型番**|**AMD EPYC 7742**|データセンター用の超高級・高性能CPUです。|
|**CPUコア数**|**128コア**|64コアのCPUが2個（2ソケット）載っており、合計128並列処理が可能です。|
|**メモリ (RAM)**|**1.0 TiB (約1,000 GB)**|桁違いの大容量です。個人PC（16GB等）の約64倍あります。|
|**ストレージ空き**|**273 GB** (全体1.5TB中)|**【注意】** 全体の82%（1.2TB）が使用済みで、残りは約273GBです。|

### 💡 このサーバーを使う上でのポイントと注意点

#### 1. 非常に重い計算やデータ処理が可能

128コア、メモリ1TBという構成なので、大規模なデータ分析、機械学習、並列プログラムのコンパイルなども余裕でこなせます。個人PCならフリーズするような処理も一瞬で終わるポテンシャルがあります。

#### 2. ディスク容量（ストレージ）の残量に注意

これだけCPUやメモリがモンスター級なのに、**ディスクの空き容量（`Avail`）は `273G`（残り18%）** と、ややタイトです。

もし何百GBもあるような巨大なデータセット（動画、AIのデータ、大規模なログなど）をダウンロードしたり生成したりすると、すぐに容量がいっぱいになってしまう危険があります。

#### 3. 他のユーザーとの共有サーバーである可能性が高い

これほどのスペックを1人で占有することは滅多にありません。メモリが「現在5.6GiBしか使われていない」ので今は空いていますが、他の人もログインして重い処理を流す共有環境（研究室や開発チームのサーバーなど）だと思われます。

サーバーの全貌が見えましたね！

# ghq + fzf + bat でプロジェクトに爆速移動する関数
function gh() {
  local src=$(ghq list | fzf --preview "bat --color=always --style=header,grid --line-range :80 $(ghq root)/{}/README.*")
  if [ -n "$src" ]; then
    cd "$(ghq root)/$src"
  fi
}
